# Data Handling Workshop: Solutions

Solutions for the Data Handling workshop (Titanic Day 1 challenge and the Online Retail final challenge).

## Contents
- `titanic/solution.py`: cleaning of the Titanic dataset (missing age, deck, embarked, fare flags).
- `retail/Final_Challenge_Solved.ipynb`: full solved notebook for the retail final challenge. Upload `online_retail_challenge.csv` to Colab before running.
- `retail/clean.py`, `retail/analysis.py`: the same cleaning and analysis as scripts.
- `retail/retail_prepared.csv`: cleaned dataset (2,069 rows).
- `retail/top5_countries.png`: chart of the top 5 countries by net sales.

## Key results
- Top 5 countries by net sales: United Kingdom (47.4%), Japan, France, Germany, Australia. Together 78.0% of net sales.
- Cancellations total about -£7,550, which is 11.3% of gross purchases.
